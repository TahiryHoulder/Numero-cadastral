Interrogation automatique ICAR_ADR_PT + CADMAP_PARCELLES (ArcGIS REST)

Critères de recherche

Remplissez au moins la rue ou la commune. Trop peu de critères = recherche longue.
Sources : ICAR — Points d'adresses et Plan parcellaire cadastral (CADMAP), Service public de Wallonie / AGDP. Le numéro cadastral (CAPAKEY) est déterminé par intersection géométrique entre le point d'adresse ICAR et la parcelle CADMAP — à vérifier visuellement sur WalOnMap en cas de doute (point d'adresse mal recalé, parcelle multiple, etc.). Lorsque plusieurs numéros de rue pointent vers la même parcelle cadastrale, ils sont regroupés sur une seule ligne (numéros séparés par une virgule). Les lignes dont le N° affiche / correspondent soit à un point d'adresse ICAR sans numéro renseigné, soit à une parcelle cadastrale sans point d'adresse ICAR propre (aucun numéro trouvé, même sous un autre nom de rue enregistré dans ICAR) mais dont la géométrie a été vérifiée comme bordant effectivement (≤ 20 m) l'axe de voirie PICC de la rue recherchée — le nom de rue provient alors de cette couche voirie, seul le code postal est estimé depuis l'adresse connue la plus proche ; en cas de doute, vérifiez sur WalOnMap. Cette vérification des parcelles "orphelines" est effectuée rue par rue (y compris pour une recherche sur toute une commune) ; une rue individuelle est ignorée si elle comporte trop de parcelles ou qu'aucun axe de voirie correspondant n'est trouvé, et l'étape entière est ignorée si le nombre de rues distinctes est trop élevé, afin d'éviter un blocage du navigateur.
